Cenvic — Complete System Data Flow Diagram

Scope: Home, Login, Signup (Request Access), Forgot Password, Reset Password | Version 1.0 | Last updated 2026-11-23 17:42 IST

No FRD, DFD, API specification or database schema has been provided. These diagrams are built only from the recorded flows, the captured DOM, the environment configuration and the approved test cases. Solid shapes are confirmed by those sources: the web application, the API reached through the API base URL, S3 image storage and the verification code email. Dashed shapes and flows (data stores, Cenvic Team, browser session) are logical items derived from observed behavior; their real names, structure and technology are not documented. The Administrator and any admin or CMS integration are not shown because they are unconfirmed (PT-018).

Notation and Legend

Gane-Sarson notation. External entities are rectangles, processes are rounded rectangles with a number, data stores are open-ended rectangles with an ID (D1, D2...), and arrows are labelled data flows (F1, F2...). Level 0 is the context diagram, Level 1 shows the main processes and data stores, and Level 2 shows the functions of one module. Reset Password is part of the Password Recovery process (4.0), so its Level 2 functions are numbered 4.6 to 4.10.
