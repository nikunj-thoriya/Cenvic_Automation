Cenvic — UI-Based Data Flow Diagram

Scope: Home, Login, Signup (Request Access), Forgot Password, Reset Password | Version 1.0 | Last updated 2026-11-23 17:42 IST

No FRD, DFD, API specification or database schema has been provided. These diagrams are built only from the recorded flows, the captured DOM, the environment configuration and the approved test cases. Solid shapes are confirmed by those sources. Dashed shapes and flows are derived from observed behavior and are not documented by the application owner. The backend is shown as a single black box (Cenvic Backend); its internal structure is not modeled here.

Notation and Legend

Gane-Sarson notation. External entities are rectangles, processes are rounded rectangles with a number, data stores are open-ended rectangles with an ID, and arrows are labelled data flows (F1, F2...). Level 0 is the context diagram, Level 1 shows the pages, and Level 2 shows the functions of one page.
