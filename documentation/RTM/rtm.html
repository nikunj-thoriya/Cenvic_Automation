Definitions

Covered: every mapped test case is Automated or Manual.
Partially Covered: some mapped test cases are Automated or Manual and the rest are not yet.
Not Covered: no mapped test case is Automated or Manual.
Execution Status: Failed if any mapped case failed; Passed if all passed; Partially Run if some passed or were skipped; otherwise Not Run. Manual cases are not run by the automation.
