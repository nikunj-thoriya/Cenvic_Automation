Recorded flows
  1. Home -> Get Started -> Login page is displayed.
  2. Click Login with empty fields -> "Email address is required" and "Password is required".
  3. Enter invalid email text, enter a password, click Login -> "Please enter a valid email address" (inline).
  4. Enter a password -> Show password -> Hide password toggles visibility.
  5. Remember Me -> check and uncheck.
  6. Login -> Request Access. -> Login -> Back to Home -> Get Started.
  7. Login -> Forgot Password? -> Back to Login.
  8. Enter an unregistered email + password, click Login -> "Email ID not registered".
  9. Enter valid email + password (from .env.dev), click Login -> "Login successfully", then redirect to /app/dashboard.
  10. Enter a registered email (from .env.dev) + an incorrect password, click Login -> "Incorrect password, please try again" toast.
      Several toasts can be visible together, so scope message checks with getByRole('alert').
  11. Enter an email with "@" but no domain extension + a password, click Login -> inline "Please enter a valid email address".

Locator notes
  Avoid recorded locators that use div filters with .nth(n) and position-based selectors
  (for example locator('div').filter({ hasText: ... }).nth(4), locator('div:nth-child(4)')).
  getByRole('strong') in the recording is not a valid ARIA role; the toast title "Cenvic" is better matched
  within getByRole('alert').
